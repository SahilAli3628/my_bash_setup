## Install tmux 
```bash
sudo dnf install tmux
```

## TPM
```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```
## To-Do
After this, tpm is cloned in ~/.tmux/plugins/tpm
Now we need to create the ~/.tmux.conf for our tmux custom config (and copy config of tmux.conf from this directory)
Now source the tmux config 
```bash
tmux source ~/.tmux.conf
```
